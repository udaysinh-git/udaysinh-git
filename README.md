# hi, i'm udaysinh

i'm a software developer and AI engineer from Pune. i run [KuroLabs](https://kurolabs.in), an eight-person software studio that does client work, open source and its own products, and i build AI products at [LifeAt](https://lifeat.io). most of what lives here is me making cheap hardware do things the vendor never intended, plus a few apps i wanted for myself. i like cats and kumputers.

the long-form version of all this, including the private builds, is on [udaysinh.me](https://udaysinh.me/projects/).

## taking things apart

- [boat-watch](https://github.com/udaysinh-git/boat-watch): a boAt Prism smartwatch driven from a PC over Bluetooth LE. custom watch faces from python, no vendor app. _(the command channel has no auth at all.)_
- [root-lenovo-tab-m8](https://github.com/udaysinh-git/root-lenovo-tab-m8): root a Lenovo Tab M8 HD, flash a LineageOS GSI, and bolt it to the wall as a third monitor and webcam.
- [msi-app-player-root](https://github.com/udaysinh-git/msi-app-player-root): root MSI App Player / BlueStacks 5 by injecting a setuid `su` into Root.vhd from WSL2. no Magisk, no boot hook.
- [MSI-katana-ambient](https://github.com/udaysinh-git/MSI-katana-ambient): ambilight for MSI laptop keyboards. the RGB zones follow whatever is on screen (or the audio) over raw USB HID.

## building things

- [avar](https://github.com/WeLabs-in/avar): an encrypted secrets CLI in Rust. local vault, repo-aware shell activation, per-recipient team sharing, zero plaintext on disk. ships with a python wrapper.
- [gimmethatdata](https://github.com/udaysinh-git/gimmethatdata): an async scraper with a terminal UI. crawls a site into clean markdown, escalates from plain HTTP to a real browser only when it has to, resumable, with an Instagram archiver.
- [Rupant](https://github.com/udaysinh-git/Rupant): privacy-first file transformation that works entirely offline.
- [QeBoard](https://github.com/udaysinh-git/QeBoard): a remote keyboard with a terminal UI. control any machine over LAN or WAN. i was too broke to buy a new keyboard.
- [Chat2DB](https://github.com/udaysinh-git/Chat2DB): gossip with your database instead of writing SQL.
- [Tome-Reader](https://github.com/udaysinh-git/Tome-Reader): a reader for EPUB, PDF and CBZ with bookmarks, highlights, word definitions and folder sync.
- [Fragmentor](https://github.com/udaysinh-git/Fragmentor): a shazam clone. audio gets sliced, fingerprinted and matched.
- [Scam-Protection](https://github.com/udaysinh-git/Scam-Protection): a Discord bot that kept 30,000+ users away from fake nitro links and hijacked accounts.
